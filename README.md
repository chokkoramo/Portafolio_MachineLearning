# Portafolio Machine Learning

Este repositorio contiene una aplicación principal en Streamlit que centraliza enlaces a diferentes proyectos de Machine Learning.

## Rutas del portafolio

### Ruta principal
- `/` (aplicación principal de Streamlit): muestra la portada del portafolio y las tarjetas con enlaces a cada proyecto.

### Enlaces/rutas de proyectos
- **Predictor en vivo**: `https://app-preview-jesduhbggg3wn7jdror8pb.streamlit.app/`
  - Predicción de datos con regresión lineal.
- **Agrupamiento con K-Means**: `https://kmeans-logisticregression-svc.streamlit.app/`
  - Agrupamiento de datos usando K-Means.
- **Árboles de Decisión**: `https://decisiontreejuank.streamlit.app/`
  - Ejemplo de clasificación con árbol de decisión.
- **Regresión Logística**: `https://logisticregressionjuank.streamlit.app/`
  - Ejemplo de clasificación con regresión logística.
- **Consumo Energético**: `https://consumo-energetico-juank.streamlit.app/`
  - Predicción de consumo energético.

### Recurso adicional
- **Sitio de páginas y ejercicios prácticos**: `https://sites.google.com/view/aplicacionesdeia/inicio`

## Ejecución local
1. Instalar dependencias:
   - `pip install -r requirements.txt`
2. Ejecutar la app:
   - `streamlit run app.py`
